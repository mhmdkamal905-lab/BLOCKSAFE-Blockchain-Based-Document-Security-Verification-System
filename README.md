# BLOCKSAFE ETHEREUM
### Blockchain-Based Document Security & Verification System

**BLOCKSAFE** is a digital document security platform designed to improve document integrity, authenticity, and transparency through cryptographic hashing and blockchain technology.

The system combines **SHA-256 cryptographic hashing** with **Ethereum blockchain integration** to provide a mechanism for verifying whether a digital document has been modified after its initial registration.

BLOCKSAFE is developed to address the growing need for secure, transparent, and reliable digital document management in organizations, institutions, and business environments.

## Key Features

- **Secure Document Upload** – Upload and manage digital documents through a centralized platform.
- **SHA-256 Hash Generation** – Generate unique cryptographic fingerprints for uploaded documents.
- **Document Integrity Verification** – Compare original and current document hashes to detect modifications.
- **Verification History** – Record document verification activities and their results.
- **Ethereum Blockchain Integration** – Support blockchain-based recording and verification of document integrity data.
- **Document Management** – Organize and monitor registered digital documents.
- **Authentication System** – Provide controlled access to application features.

## System Architecture

BLOCKSAFE follows a document verification workflow:

1. User uploads a digital document.
2. The system generates its SHA-256 hash.
3. Document metadata and hash information are stored in the database.
4. Blockchain integration can record the document hash on Ethereum.
5. When verification is requested, the system generates a new hash.
6. The new hash is compared with the original hash.
7. Verification results are recorded and displayed.

## Verification Status

- **VALID** – The document hash matches the original hash.
- **INVALID** – The document hash does not match the original hash.
- **MISSING** – The original document file cannot be found in storage.
